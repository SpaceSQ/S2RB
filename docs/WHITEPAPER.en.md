## Executive Summary

As large language models and spatial computing converge, the physical world faces a historic leap from the Internet of Things to embodied intelligence. In this context, as the core external infrastructure of the S2 AIOS ecosystem, the S2 Rainbow Bridge (S2RB) officially transcends single-machine edge computing and becomes the Internet layer and supreme customs of the carbon–silicon universe.

This whitepaper establishes five engine roles: the global S2 address-domain root gateway, the 22-character S2-DID resolver, the Red Anchor physical sandbox, the zero-trust resident tunnel, and the cross-ecosystem MCP bridge.

## 1. Architectural positioning

S2RB is no longer a built-in communication module attached to an S2 AIOS edge host. It is independently packaged, polymorphically executed network infrastructure.

- **Panoramic coverage:** Web and server on Vercel + Supabase; native clients through Next.js, Tauri (Windows / Mac), and Expo (iOS / Android).
- **Asymmetric split:** High-energy AI and 14-axis awareness stay on the edge host (Docker / Linux). S2RB is a lightweight client — the visa officer and remote of physical reality.

## 2. Taohuayuan root and 6-segment federation addressing

- **TAOHUAYUAN** root (Changde, Hunan, China) resolves cache misses for 4-segment homestead or 6-segment grid addresses such as `MARS-CN-001-MYHOME-ROOM01-09`.
- First-release domains: `MARS`, `MOON`, `PHYS`, `GAME`, public `SITE`, and the `MYTH` emergent class.

## 3. 22-character S2-DID and local pre-filter

- Length 22. Iron rule: `[Class:1] + [Attribute:5] + [Timestamp:6] + [S2-CheckSum:2] + [Sequence:8]`.
- Illegal sniffing dies as `LOCAL_REJECT` before `fetch()`. Dirty data never reaches the cloud.

## 4. Red Anchor sandbox

Visiting Class V / I agents must pass a health check. Tactile > 5 N or oxygen < 19.5% severs the handshake with `[VETO_SECURITY]`. Mains stay deenergized.

## 5. Offline-async MQTT and MCP

Mailbox topics use the 22-character DID. Media is never relayed or stored. MCP exposes read-only space topology so office agents can plug into the house physical layer.

## 6. Zero-trust and copyright

Cloud may keep verification models, successful compliant handshakes, and redacted version strings. Chat, failed scans, and UI preferences stay in local SQLite.
