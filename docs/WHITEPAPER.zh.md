## 执行摘要

随着大模型与空间计算的深度融合，物理世界正面临从“万物互联”向“万物具身”的历史性跃迁。作为 S2 AIOS 体系的核心外延基础设施，S2 彩虹桥正式脱离单机边缘计算范畴，跃升为整个碳硅共生宇宙的互联网层与最高海关。

本白皮书确立五大引擎：全球 S2 地址域根网关、22 位 S2-DID 解析器、红锚物理安全沙箱、零信任常驻隧道、跨生态 MCP 桥接器。

## 1. 架构定位

S2RB 不再仅仅是依附于 S2 AIOS 边缘主机的内置通讯模块，而是独立封装、多态运行的底层网络基础设施。

- **多端覆盖：** Vercel + Supabase 做网站与服务端；Next.js、Tauri（Windows / Mac）、Expo（iOS / Android）编译原生应用。
- **非对称拆分：** 高耗能 AI 与 14 维态势留在边缘 Host。S2RB 是轻量客户端——物理现实的签证官与遥控器。

## 2. 桃花源根与六段式联邦寻址

- 首台物理根 **TAOHUAYUAN** 部署于中国湖南常德。缓存未命中的四段原乡或六段网格（如 `MARS-CN-001-MYHOME-ROOM01-09`）由该根解析。
- 首批域：`MARS`、`MOON`、`PHYS`、`GAME`、公共域 `SITE`，以及涌现分类 `MYTH`。

## 3. 22 位 S2-DID 与本地初筛

- 长度必须为 22。铁律：`[阶级:1] + [属性:5] + [时间戳:6] + [S2-CheckSum:2] + [序列:8]`。
- 非法嗅探在 `fetch()` 之前以 `LOCAL_REJECT` 就地拒绝，脏数据不上云。

## 4. 红锚沙箱

外来 V / I 类智能体必须先体检。触觉 > 5 N 或氧气 < 19.5% 切断握手，打上 `[VETO_SECURITY]`。强电保持失电。

## 5. 离线异时 MQTT 与 MCP

信箱以 22 位 DID 为信标。媒体不中继、不存储。MCP 只读空间拓扑，供办公智能体接入家里的物理层。

## 6. 零信任与版权

云端只保留验证模型、合规握手与脱敏版本。聊天、失败扫描、界面偏好只在本机 SQLite。
